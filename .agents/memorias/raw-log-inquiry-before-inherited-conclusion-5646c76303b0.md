# raw-log-inquiry-before-inherited-conclusion

Espelho da auto-memory do host ZCode (arquivo raw-log-inquiry-before-inherited-conclusion.md, tipo feedback).

When the owner shows a screenshot or asks to "look", interrogate raw

The owner pasted a screenshot of the OpenBot custom-provider dialog with "Executa em" limited to OpenCode and Pi, asking "não tem suporte pro zcode?". The right response was not a verdict from the screen or from the earlier conversation. It came from going down to raw evidence: the bundled CLI's `--help` (`node <app>/resources/glm/zcode.cjs --help`), a string scan of `app.asar`, the live ACP registry JSON, `packages/contracts`, and the canonical `mentor-documental-zcode` corpus.

**Why:** an earlier turn had already concluded the owner's Linux assumption was the blocker; the screenshot showed that conclusion was narrower than the real question. Only raw sources separated "UI setting" from "protocol missing".

**How to apply:** on any "look at this / is there support for X" request, run `METODO-INTERROGAR-PARA-SOLUCIONAR`: open `--help`, scan the installed bundle, check the live registry, read the contract file, and query the mentor corpus — then answer with a source-per-claim table. State the unconfirmed items explicitly instead of guessing. See [[openbot-provider-integration-limits]].
