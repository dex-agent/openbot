# owner-asks-for-archeologia-pipeline

Espelho da auto-memory do host ZCode (arquivo owner-asks-for-archeologia-pipeline.md, tipo feedback).

The owner runs full W-1..W10 archeology blocks with a fixed

When the owner asks for "arqueologia completa W0-W10", they expect: CRG consulted first (skill `code-review-graph`), read-only source until a green build/test receipt (or a red route with owner and when), a byte-level encoding table before edits, 3rd-party in two columns with license, sanitized secrets only, native parser for W7, the podium of God Class/Long Method/CC, and at the close: inventory, Enc table, graph, JSON receipt, exit measured without a pipe, tool panel delta, and memory/tropeço counts. Commits go local at each block close; never push.

**Why:** this was the explicit command of the block, and the house rules make the closing format mandatory.

**How to apply:** start from `arqueologia-warmup-base` plus the matching dialect; keep `$chato`, `$burrinha`, `$critico-cetico`, `$entrevista-me`, `$questionador` and `$interrogador-documental` as live lenses and credit them; close with the table of finding→cure, executable proof with numbers, and the memory ritual.
